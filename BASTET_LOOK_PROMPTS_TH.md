## ทำไมเปลี่ยน
- **ยังเป็นลุคแบน** ขณะที่หมาป่า จากัวร์เป็น 2.5D ในเกมแล้ว แรด แมว จิ้งจอกกำลังตามมา
- **หน้าคนมีหูแมว** (ผิวคน มือคน) ส่วนฮีโร่สัตว์ตัวอื่นหน้าเป็นสัตว์ · แมวกับจิ้งจอกรอบใหม่ก็ไปทางหน้าสัตว์
- **ผมเปียยาว + ผ้าคลุมหลังหัว + กระโปรงยาว + พู่หลายพวง:** ตอนตัวเล็กในเกมเป็นก้อน ลายแตกเป็นจุด
- **น้ำเงินเข้ม + ทอง + ครีม** ซ้ำอนูบิส (ดำ ทอง ลายน้ำเงิน-ทอง ผ้าลินินขาว) กับฮิปโป (เทาฟ้า เขียวน้ำทะเล ขาว ทอง) → ฮีโร่อียิปต์ 3 ตัวสีชุดเดียวกัน · ไม่มีอะไรบอกสาย A คำสาปม่วง / B สุสาน

## กติกา (อยู่ในทุกกล่องแล้ว)
- **ลุค 2.5D** เหมือนฮีโร่ 3 ตัวในภาพแนบแรก: โมเดล 3 มิติทูนเชด เส้นขอบน้ำตาลเข้มแบบวาดมือ แสงหลักซ้ายบน ขอบสว่าง ผิวด้าน มองลงจากบน ~30° · ลอกแค่ลุค ไม่ลอกตัว
- **แมวจริงแบบจากัวร์:** หน้ามีขน ปากสั้น จมูกแมว หนวด ตาโต หูแหลมใหญ่ มือเท้ามีขน หางยาว · ไม่ใช่หน้าคนมีหู (ยกเว้นแบบ 5)
- **หัว หน้า หูเห็นทุกมุม:** ห้ามมงกุฎใหญ่ ผ้าโพกหัว ฮู้ด ผ้าคลุมหัว / หน้า · เครื่องประดับหัวเล็ก หูว่าง
- **คัมภีร์ลอยเหนือฝ่ามือซ้ายทุกมุม** ขนาดราวหัว อยู่ในภาพทั้งหมด **ไฟฟ้าเล็กบนหน้ากระดาษเสมอ** (ไม่มีแสงอื่นบนตัว) · ไม่ถือไม้เท้า / คทา / ดาบ · อังค์ทองเล็ก + **เครื่องรางซิสตรัม** (กระดิ่งวัด: ห่วงบนด้ามสั้น มีแกน 3 เส้น) ห้อยที่เข็มขัด
- ชิบิ ~3 หัว · ชุดไม่เกินเข่า ไม่มีแขนเสื้อห้อยยาว · ของห้อยน้อย · **สีเป็นก้อนใหญ่** (ขน + ผ้าหลัก + สีเน้น 1 สี + ทอง) · ห้ามลายจุกจิกเต็มตัว
- สีเวทในเกม = **ไฟวิญญาณฟ้า + คำสาปม่วง + แสงทอง** ชุดสะท้อนเป็นสีเน้นได้
- **ห้ามเขียว** (คลิปตัดพื้นเขียว) เทอร์ควอยซ์ต้องเป็นฟ้าชัด · ไม่ซ้ำฮีโร่อื่น (โดยเฉพาะอนูบิส ฮิปโป จากัวร์ แมวเนโกะมาตะ แกะ จิ้งจอก) · ไม่ลอกตัวละครแมวจากเกม / อนิเมะ · ห้ามตัวอักษร / อักษรภาพ (ลายเป็นรูปทรงง่าย: ตา อังค์ สคารับ ดอกบัว จานสุริยะ ดาว ซิกแซก)
- **ชีต:** ซ้าย = ภาพใหญ่ตามท่า · ขวาบน = หน้า / ข้างหันขวา / หลัง ยืนเฉยๆ คัมภีร์ลอยมือซ้าย · ขวาล่าง = ท่าร่าย 2 ท่า: ผลักกรงเล็บ สัญลักษณ์คำสาปม่วง + ตั๊กแตน (สาย A) · ชูคัมภีร์ มัมมี่เล็ก 2 ตัวโผล่จากทราย วิญญาณฟ้า (สาย B)
