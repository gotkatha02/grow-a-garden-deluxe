## ทำไมเปลี่ยน
- **ยังเป็นลุคแบน** ขณะที่หมาป่า จากัวร์เป็น 2.5D ในเกมแล้ว แรด แมว จิ้งจอกกำลังตามมา
- **หน้าคนมีเขา** (ผิวคน มือคน เท้าคน ไม่มีหูแกะให้เห็น) ส่วนฮีโร่สัตว์ตัวอื่นหน้าเป็นสัตว์ · แมวรอบใหม่ก็ไปทางหน้าสัตว์
- **ตัวเล็กมากในเกม** (`HERO_SIZE` .598 = สูงราว 2 ใน 3 ของแรด / จระเข้ · เล็กเป็นอันดับ 3 ของเกม) แต่ชุดเต็มไปด้วยรายละเอียด: ผมยาวเลยสะโพก + ผ้าคลุมยาว + กระโปรงจีบหลายชั้น + ลายกรีกทุกขอบ + ใบลอเรล + เพชรหลายเม็ด → ในเกมเป็นก้อนชมพู-ม่วง ลายแตกเป็นจุด (ตอนทำคลิปก็เจอแล้ว: ตัวสูงแค่ ~240 px ในคลิป รายละเอียดเละ)
- **ขาว + ม่วงน้ำเงิน + ทอง + ลายกรีก + ลอเรล ซ้ำสิงโตขาว** (ฮีโร่กรีกด้วยกัน: เสื้อขาวแผงกรมท่าขอบลายกรีกทอง มงกุฎลอเรล)
- **ไม่มีอะไรบอก "ขนทอง"** ทั้งที่ชื่อ Golden Sheep และระบบหลักของเธอคือขนทองงอก / ตัดขนไปทำโล่-ฮีล (ผมชมพู พรอมต์คลิปเดิมยังต้องห้ามพูดว่าทอง) · ไม้เท้าไม่ใช่ไม้คนเลี้ยงแกะ ทั้งที่ตีปกติชื่อ Crook Combo · ไม่มีอะไรบอกสาย A ฮีล / B สะกด

## กติกา (อยู่ในทุกกล่องแล้ว)
- **ลุค 2.5D** เหมือนฮีโร่ 3 ตัวในภาพแนบแรก: โมเดล 3 มิติทูนเชด เส้นขอบน้ำตาลเข้มแบบวาดมือ แสงหลักซ้ายบน ขอบสว่าง ผิวด้าน มองลงจากบน ~30° · ลอกแค่ลุค ไม่ลอกตัว
- **แกะจริงแบบจากัวร์:** หน้ามีขนสั้น ปากสั้นมน จมูกแกะ ตาโต หูยาวกางข้าง **ขนแกะฟูเป็นก้อนบนหัวแทนผม (ยาวแค่ไหล่)** มือมีขน กีบเท้า (หรือรองเท้าถ้าแบบนั้นกำหนด) หางสั้นฟู · ไม่ใช่หน้าคนมีเขา (ยกเว้นแบบ 5)
- **เขาแกะม้วนแนบข้างหัว** เขา หู หน้า และกลางหัวว่างทุกมุม: ห้ามมงกุฎใหญ่ ฮู้ด ผ้าคลุม หมวก (หัวว่างไว้ใส่หมวกแฟชั่นทีหลังได้) · เครื่องประดับหัวเล็ก
- **ไม้เท้าคนเลี้ยงแกะในมือขวาทุกมุม:** สูงราวตัว ปลายบนงอเป็นตะขอใหญ่ **ลูกแก้วกลมนั่งในวงตะขอ** สีที่มีบนตัวแค่จุดเดียว ไม่เรืองแสง อยู่ในภาพทั้งหมด · ไม่มีอาวุธอื่น ไม่สะพายของบนหลัง (แบบ 5 = ไม้เท้าเดิม)
- **ขนต้องอ่านออกว่าเป็นขนแกะ** ก้อนหยิกกลมฟู ขอบชัด ไม่ใช่เส้นผม
- ชิบิ ~3 หัว ตัวกลมเล็ก · ชุดไม่เกินเข่า ไม่มีแขนเสื้อห้อย ผ้าคลุมไม่ยาวเกินสะโพก · ของห้อยน้อย · **สีเป็นก้อนใหญ่** (ขน + ขนหน้า + ผ้าหลัก + สีเน้น 1 สี + ทอง) · ลายขอบไม่เกิน 1 แถบ
- สีเวทในเกม = **แสงทอง + ขนทอง (ฮีล โล่) · ชมพูบานเย็น + ม่วง + ลาเวนเดอร์ (สะกด)** ชุดสะท้อนได้
- **ห้ามเขียว** (คลิปตัดพื้นเขียว) ใบไม้ทุกใบเป็นทอง · ไม่ซ้ำฮีโร่อื่น โดยเฉพาะ**สิงโตขาว**กับ**ลูกมังกรช่างตีเหล็ก** (กรีกด้วยกัน) + บาสเทต (เพิ่งเลือกแบบ 4 ธิดาแห่งรา = แมวขาวหิมะ ชุดขาว ผ้าคาดแดงสด จานสุริยะทอง) จิ้งจอก แอคโซลอทล์ จากัวร์ แมว ลิง หมาป่า นกฮูก แรด · แบบ 1–4 ไม่ซ้ำแกะตัวปัจจุบันด้วย · ไม่ลอกตัวละครแกะจากเกม / อนิเมะ · ห้ามตัวอักษร / อักษรกรีก (ลายเป็นรูปทรงง่าย: ลายกรีก คลื่น ดวงอาทิตย์ ดาว ก้นหอย ใบลอเรล)
- **ชีต:** ซ้าย = ภาพใหญ่ตามท่า · ขวาบน = หน้า / ข้างหันขวา / หลัง ยืนเฉยๆ ไม้เท้ามือขวา · ขวาล่าง = ท่าร่าย 2 ท่า: ชูไม้ฮีล แสงทองรวมในลูกแก้ว โล่ฟองทองขอบขนแกะ ขนทอง + โน้ตทองลอย (สาย A) · หลับตาร้องเพลง ยื่นไม้ ด้ายทองพุ่งเป็นเกลียวจากลูกแก้ว + รูนเพชรบานเย็น โน้ตม่วง ฟองฝันลาเวนเดอร์ (สาย B)

2. ภาพตั้งต้น (`tools/dir8cut.py startv` ทีละมุม 1024² ht ~490 feet .88 clean=0 — เว้นที่บนหัวให้ท่าชูไม้) + พรอมต์คลิป 20 อัน (เพิ่ม `sheep25` ใน `tools/clip_prompts.py` แบบ wolf25 / jaguar25 / kitsune25 — ลุค 2.5D, ตาลืมตลอดคลิปยืน (คลิปยืนเดิมหลับตานานจนต้องเลือกช่วง loop), เดินไม่เข้าหากล้อง, ลูกแก้วไม่เรือง, ไม่มีเส้นสวิง / ประกาย (คลิปตีเดิมมีวงสวิงกับประกายติดมา ต้องข้ามเฟรม)) — ท่าที่เกมใช้:
   - **ท่าตี** = จับไม้สองมือ ง้างข้ามไหล่ ฟาดเฉียงลงหน้าตัว ลูกแก้วนำ ค้างนิดตอนโดน (เฟรม contact = ลูกแก้วต่ำสุดหน้าตัว) แล้วกลับท่ายืน · ไม่ใช้คำ attack / strike · อากาศรอบไม้เป็นเขียวเรียบ ไม่มีเส้น / วง / แสง
   - **ท่าร่าย (buff)** = ชูไม้เหนือหัวสองมือ ลูกแก้วชี้ฟ้า ค้าง ~1 วิ แล้วลดกลับ · สกิลร่ายทุกอัน + ค้างเฟรมนี้ตอนชาร์จ Light Ball
3. คลิปมา → `tools/cliphero.py` → `assets_sheep25.js` (prefix SHE, ไฟล์แยก + สวิตช์ URL แบบ `?jg25=0`) คงเวลาเฟรมของ `assets_sheep.js`:
   - ท่าตี 12 เฟรม 820 ms [60 × 8, 70, 80, 90, 100] contact 8 (ดาเมจที่ 480 ms) ทุกทิศ · atkRemap {}
   - ท่าร่าย 12 × 80 ms (960 ms) peak 7 ทุกทิศ
   - เดิน 8 เฟรม (S 146 · SE / E / NE 125 · N 151 ms ต่อเฟรม = จังหวะคลิปเดิม) · ยืน 12 เฟรม (S 118 · SE 125 · E 170 · NE 83 · N 62 ms) · โดนตี 7 × 70 ms
   - socket = ลูกแก้วบนไม้ทุกเฟรม (`orbAll` + `orbMask` สีลูกแก้วใหม่ + `orbPale` + `orbFix` + `orbLerp`) → `sheep_vfx.js` `crook()` / `tip()` / `headZ` · `window.HUD_FACE` จาก view_S · `CHAR_SCALE.sheep` วัดใหม่ (`HERO_SIZE` .598 คงไว้)
