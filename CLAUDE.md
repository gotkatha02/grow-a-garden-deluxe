# Totem Legend — rules for Claude

The owner (Thai speaker) builds this game across many chats. Reply in Thai. Commit and push finished work to this repo; no zip files.

## Design rules (owner's, apply to every hero and system)
1. **12 Tails style.** Skill trees: Basic + Class A + Class B (two clearly different play styles) + Class C (12 nodes: Basic / A / B columns, unlocked at Lv 55 / 60 / 70 / 80). Zigzag levelling between a row-1 skill and its partner. A and B must be different play styles (not the same kit with other numbers). Each C node is an upgrade of, or a new skill tied to, the Basic / A / B skill in the same row.
2. **No percent effects.** Use flat values (ATK +X, damage taken −X per hit, shield = level × n). Random chances become counters ("every 4th hit"). Exception (owner 2026-11-19): the item system may keep its percents and chances — special stats, item traits, refine success, drill holes, drop rates (items.js / ITEM_SYSTEM_TH.md).
3. **Skill power is written as ATK×n or TAL×n.** The number shown already includes the hero's coefficient (`CHAR_COEF` in index.html).
4. **Attack speed is fixed per character** (`CHAR_ASPD`). No skill, stat or item changes it.
5. **Balance:** no hero stronger than the others. Target bench score ≈ 2,450 (tank Rhino ≈ 2,250). Two-way heroes are tested per branch (A alone, B alone) with a TAL build.
6. **Pictures are the main effects, code VFX supports them.** Placeholder sprites are fine until real art arrives. Art prompts for ChatGPT: cartoon style matching the characters, one prompt per copy box, sent one at a time.

## Stats and damage (12 Tails formulas)
- Stats: ATK DEF AGI VIT INT CHA TAL LCK. Total = points + level growth + items/buffs.
- Level growth = floor((Lv − 1) × (base + 3) × 0.083). Base is rolled at character creation (class base → +1 ×4 random → −1 ×4 random → +1 all, clamp 3–12; reroll unlimited).
- 2 stat points per level, each point costs 1. One stat maxed by points + level growth ≈ 300; the best items add only ≈ 50 more (≈ 350 total, owner 2026-11-19).
- Physical skill = coefficient × ATK. Magic / heal = coefficient × TAL power, TAL power = 50 × (1 + 0.02 × TAL).
- Target DEF: 35% × (d − DEF/2) + 65% × d × (1 − DEF/(DEF + 64)). Crits skip DEF. LCK adds a small random roll and crit +0.1 per point.
- AGI: cooldown × (1 − AGI/(AGI + 128)). CHA: buff duration × (1 + 0.015 × CHA); statuses on monsters × (1 + (CHA − monster CHA)/100), no upper cap. AGI move speed has no cap either (owner: the more you put in a stat, the bigger its effect; builds = ATK normal hits / TAL skills / CHA buffs+debuffs / VIT tank / AGI run + spam).
- One-way builds: pure classes use one stat for everything. Two-way heroes (wolf, jaguar, owl, hippo, dragon, lion), owner 2026-11-19: normal attack = ATK only; magic-looking skills = TAL only; physical-looking skills = type 'x' = ATK 30% + TAL power 70% (MIX in skill_rules.js, tooltip shows 'ผสม×n'); Basic-branch 'b' skills = the higher of the two. Two-way heroes are benched with the TAL preset, each branch alone (benchall.py BRF).
- Items: stats ×0.1 scale (ITEM_STAT_SCALE). Orbs T1–T3 +1, T4 +1–2 (12 Tails has 3 gear pieces × 4 holes; we have 8 pieces / 16 holes, so orbs stay tiny). Holes: weapon / armour 4, other gear 2, accessories none.

## Art prompts (what to write when the owner asks for an image or effect prompt)
- Look: friendly hand-painted chibi cartoon matching the game, thick clean dark-brown outlines, cel shading with 2–3 flat tones, soft cartoon glow, bright and warm. Not realistic, not painterly smoke, not 3D. Say this in every prompt.
- Always tell the owner to attach the campfire key art (style) and the hero's character sheet (look). Describe the hero's outfit in the prompt too.
- One prompt per copy box, English prompt, Thai explanation around it. No text / logo / watermark in images.
- Skill effects: ONE effect per image, transparent PNG background, empty space on every side. Never sprite sheets on magenta/green (cut-outs break and red/pink parts vanish). State the view: ground pieces = flat wide ellipse seen 3/4 top-down; streaks/slashes = side view pointing right; upright pieces (spirit, aura, dome) = flat base at the bottom.
- Skill icons: 4×3 sheet 1536×1024, rounded square with thick shiny gold frame, chibi hero acting the skill, background colour per branch, "each icon is a perfect square". Save the prompts as <HERO>_ICON_PROMPTS_TH.md with a slot → skill key table.
- Skill tree backgrounds: vertical 2:3, full-body hero in the lower middle, theme of the branch, top 15% kept simple, medium-light colours (icons sit on top). Basic = start of journey, A / B = their play style, C = legendary with the hero's giant spirit behind.
- Fixing a generated image: tell the owner to brush-select only the part to change in ChatGPT, one character at a time; whole-image edits redraw everything.

## Placing effects in game
- Toon VFX layer (vfx_layer.js, owner 2026-11-19, only the 4 heroes with generated FX pictures: dragon, kitsune, anubis, lion): every painted piece goes through TV.Piece = anticipation pull-in → overshoot pop + squash/stretch + white flash frame → secondary by type (ground: outlined shockwave ring + rim bits + glow; stand: rise + base ring + rising sparkles; streak: afterimages + speed lines + trail; hit: comic spiky burst + bits; aura: orbiting sparkles) → dissolve into outlined particles sampled from the picture's pixels. Particle family comes from the picture's hue or TV.hint(hero,{piece:'water'|'fire'|'electric'|'sand'|'stone'|'shadow'|'gold'|'light'|'nature'}) at the end of each char_<hero>_fx.js. Pictures a hero file draws itself (beams, pillars, falling suns, bolts) call TV.fxAt / TV.once / TV.trailFx. Frame-strip check: /home/claude/work/strip.py hero keys times. Extended 2026-11-19 to every hero that has painted FX pictures (also wolf, cat, hippo, croc, jaguar, owl, rhino): their own piece classes (WImg, KtImg, HImg, CxImg, JxImg, OxImg, RxImg) keep drawing themselves and TV.attachOld() hooks addFx to add a TV.Companion per piece (contact shadow, rings, bursts, picture-coloured particles, dissolve); wolf_fx.js exposes window.wImg for this. Grounding: TV.Contact puts a dark contact shadow + coloured light pool under upright pieces, heavy elements (water/sand/stone/gold) dissolve with gravity onto the floor, overshoot is soft (1.25). Bastet / axolotl / sheep have no pictures yet and are untouched.
- Ground pieces lie flat on the ground layer under the feet; upright pieces stand from the ground (anchor at the bottom); streaks aim along the attack at weapon height; never lay side-view art flat and spin it.
- Debris (shards, drops) fly with gravity, land, fade. Hit sparks sit on the target body, short.
- Files: effects assets/fx/<hero>/*.webp, icons assets/icons/<hero>/<skill key>.webp (128×128), branch art SKILL_BG_ALL in assets_skillbg.js, per-hero effect code char_<hero>_fx.js.
