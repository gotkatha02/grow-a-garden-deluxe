# สตูดิโอเอฟเฟกต์ Godot (Totem Legend FX Studio)

เจ้าของสั่ง 2026-11-27 "ทำเอฟเฟคสกิลใหม่โดยใช้ godot ได้ไหม ทำตามคอนเสปสกิลเลย เริ่มที่หมาป่าก่อน ทำให้มันเข้ากับเกม" → "เริ่มนำร่องเลย"

เกมเป็น HTML จึงรัน Godot ในเกมไม่ได้ — โฟลเดอร์นี้คือ **โปรเจกต์ Godot 4.7 ที่ใช้ "วาด" เอฟเฟกต์** (shader + ชิ้นที่วาดด้วยโค้ด ทุกอย่างเป็นฟังก์ชันของเวลา เรนเดอร์ซ้ำได้ผลเดิม) แล้วเรนเดอร์ทีละเฟรม (พื้นโปร่งใส) แพ็กเป็น webp ให้เกมเล่นด้วย `wolf_gfx.js` ตามจังหวะของเกมเอง

## ครบทุกสกิลที่ v5 วาด (เจ้าของ "ทำต่อทั้งหมด" 2026-11-27) — `?wgx=0` = กลับไปใช้ v5

## นำร่อง 3 สกิลแรก

| สกิล | ชิ้นจาก Godot | เกมเล่นยังไง |
|---|---|---|
| ตีปกติ (Wolf Combo) | `slash_steel` แถบคมขวานเหล็กน้ำเงิน + เส้นรูน · `hit_steel` | แถบถูก **งอตามเส้นทางหัวขวานจริงของสไปรต์ทุกเฟรม** (ใช้รูปทรงเดียวกับ VSlash ของ v5) จบที่เฟรมโดนพอดี · ตอนโดน = ภาพโดนหมุนตามทิศที่ฟัน |
| Blood Cleave | `slash_blood` เสี้ยวเลือดขอบขาวร้อน หยดย้อย · `blood_wave` คลื่นเลือดวิ่งบนพื้นทิ้งรอยเลือด · `hit_blood` | คลื่นวาดแบบมองจากบน เกมวางบนพื้นตามทิศที่หัน (บีบตามมุมกล้อง K) ตรงตำแหน่ง/เวลาที่ v5 ปล่อยคลื่น |
| Frost Fang | `slash_ice` เสี้ยวน้ำแข็งฟันผลึก · `ice_fangs` กลุ่มหนามน้ำแข็ง ผุด · ค้าง (วนแสงวิ่ง) · แตกเป็นเศษ · `hit_ice` | หนามขึ้นตรงผลึกที่ **คลื่นดาเมจจริง** สร้าง (ขนาด = ความสูงผลึก ×1.9) ค้างตามอายุผลึก แล้วแตก |

ดาเมจ / จังหวะโดน / สถานะ ไม่เปลี่ยน — ไฟล์นี้แค่เปลี่ยนภาพที่วาด

## หน้าตา (ตามที่เจ้าของเคยสั่ง)
- สีชุดเดียวกับ v5 (เหล็กน้ำเงิน · แดงเลือด · ฟ้าน้ำแข็ง) แกนขาว ขอบเข้มรองใต้ชิ้นให้อ่านออกบนหิมะ
- แสงเรืองน้อย (บนหิมะแสงฟุ้งจะเป็นปื้นขาว) · ไม่มีวงเวทย์บนพื้น · ชิ้นน้อย ท่าตัวละครยังเห็นชัด

## วิธีเรนเดอร์ใหม่ (Windows)
```
powershell -File tools/godot_fx/render.ps1                      # ทุกชิ้น
powershell -File tools/godot_fx/render.ps1 -Fx ice_fangs,hit_ice  # บางชิ้น
```
- ต้องมี Godot 4.7 (`-Godot <path>` หรือ env `GODOT`) และ Python 3.12 + numpy pillow
- Godot จะเปิดหน้าต่างเล็กๆ แป๊บเดียวต่อชิ้น (เรนเดอร์แบบ headless ไม่ได้ เพราะไม่มีการวาดภาพ) · ชิ้นที่ค้างเกิน 90 วิ ถูกปิดเอง
- `render.gd` เรนเดอร์ใหญ่ 2 เท่า → `pack.py` ย่อ (กันขอบหยัก) แก้สีจาก premultiplied ตัดขอบว่าง แพ็กเป็นแผ่น → `assets/fx/wolf_gd/<ชื่อ>.webp` + `meta.js` (`window.WGX_META`) และภาพตรวจ `<ชื่อ>_preview.png` (พื้นมืด + พื้นหิมะ)
- ค่าแพ็กต่อชิ้น (จุดยึด ช่วงเฟรม ขนาดอ้างอิง) อยู่ใน `fx_meta.json` — ต้องตรงกับค่าคงที่ในไฟล์ `fx/<ชื่อ>.gd`

## เพิ่มเอฟเฟกต์ใหม่
1. `fx/<ชื่อ>.gd` = Node2D ที่มี `SIZE`, `FPS`, `FRAMES` และ `set_time(t)` (วาดจากเวลาอย่างเดียว ห้ามใช้เวลาจริง/สุ่มจริง — ใช้ `common.gd` rnd()) · แถบฟันใช้ `slash_base.gd` + `shaders/slash_strip.gdshader`
2. ใส่ค่าใน `fx_meta.json` แล้วเรนเดอร์
3. ผูกใน `wolf_gfx.js` (ตาราง `SK` / hook `addFx` `hurt`)

## ตรวจแล้ว / ยังไม่ได้ทำ
- ตรวจในเกม (โหมดทดสอบ Frostheim, ร่ายทุกสกิล + สกิลต่อเนื่องผ่านหน้าต่างคอมโบ): ทุกสกิลขึ้นชิ้นจาก Godot ไม่มี error
- ยังไม่ได้เห็นในเกม: Ravenous Leap (สกิล C ยังไม่ปลดในโหมดทดสอบ — รอยแตกน้ำแข็งตอนลงใช้ระบบเดียวกับ Frozen Descent ที่ตรวจแล้ว)
- ยังไม่ได้ทำ: ตัวละครอื่น · ปุ่มเปิด/ปิดในเมนู (ตอนนี้ใช้ `?wgx=0`)
